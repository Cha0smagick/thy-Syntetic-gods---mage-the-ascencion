## 📜 Overview

**The Synthetic Gods** is an interactive, Geocities-styled digital grimoire for a *Mage: The Ascension* tabletop RPG campaign. It explores the intersection of 90s internet culture, chaos magic, and the World of Darkness—presented as an authentic 1996–1999 personal website that *is itself* a magical artifact.

The site serves as both:
- **A campaign resource** — Three acts of lore, mechanics, and story hooks for STs and players
- **A playable artifact** — Interactive sigil generator, egregore tracker, visitor counter, Neon Oracle, faction reputation system, character dossiers, and hidden rituals that respond to real user behavior
- **A meta-game** — The website *teaches you how to play* through exploration, discovery, and interaction

## 🎮 COMPLETE PLAYTHROUGH GUIDE

### 🎯 HOW TO PLAY (The Game Teaches Itself)

> **"There is no tutorial. The web is the tutorial."**

The Synthetic Gods is designed as a **discovery-based meta-game**. You learn the mechanics by *using* them. Every feature is both a game mechanic and a narrative element.

### 📋 PHASE 1: INITIATION (First Visit)

| Step | Action | Reward | Lore Significance |
|------|--------|--------|-------------------|
| 1 | Load the page | Visitor Counter increments | You've entered the Digital Web |
| 2 | Read the header sigils (View Source) | Hidden knowledge | The Webspinner's first axioms |
| 3 | Wait 30 seconds | Background may shift | The Digital Web is alive |
| 4 | Move mouse | Sparkle trails appear | Your presence leaves resonance |
| 5 | Type Konami Code (↑↑↓↓←→←→BA) | **GOD MODE** unlocked | You've proven worthy |

### 📋 PHASE 2: SIGIL CRAFTING (Act I)

**Location:** Main page → Sigil Workshop section

```
1. Click "SIGIL WORKSHOP" in nav or scroll to ⟐ SIGIL WORKSHOP ⟐
2. Enter your INTENT (max 100 chars)
   Example: "MY CODE COMPILES WITHOUT ERRORS"
3. Click GENERATE SIGIL
4. Observe the 5 arrangements:
   - LINEAR:  Raw consonant string
   - MIRRORED:  Palindromic reflection
   - SPIRAL:  ASCII spiral matrix
   - GRID:  Square grid layout
   - RUNIC:  Elder Futhark transliteration
5. Copy the EMBED CODE for your own pages
6. Watch the CHARGE bar fill (feeds egregore)
```

**Mechanics:** 
- Intent → Remove vowels/duplicates → Pad to 8+ chars with mystical symbols (@#$%&*+=)
- Each generation adds +5 Egregore Power
- Sigils persist in localStorage across sessions

### 📋 PHASE 3: EGREGORE CULTIVATION (Act II)

**Location:** Sidebar → Egregore Tracker

| Power Level | Title | Effects | Requirements |
|-------------|-------|---------|--------------|
| 0-10 | Dormant | Baseline | First visit |
| 11-30 | Stirring | Guestbook glows | 5+ sigils charged |
| 31-50 | Awakening | Hidden links reveal | 20+ sigils, 100+ visits |
| 51-80 | Manifest | Ritual Hour bonuses | Daily visits for 7 days |
| 81-100 | Symbiosis | **Astrosoma threshold** | 10,000+ worshippers (simulated) |

**Daily Rituals:**
- Visit daily → +1 Egregore Power (10% chance per visit)
- Generate sigil → +5 Egregore Power
- Sign guestbook → +2 Egregore Power
- 3:33 AM GMT visit → +10 Egregore Power + exclusive content

### 📋 PHASE 4: THE NEON ORACLE (Act II Expansion)

**URL:** `pages/neon-oracle.html` (linked in Webring)

```
1. Navigate to NEON ORACLE via Webring sidebar
2. Read DAILY FORTUNE (date-seeded, consistent per day)
3. Click REFRESH FORTUNE for new roll (costs 1 Egregore Power)
4. ASK THE ORACLE:
   - Type question in textarea
   - Click QUERY ORACLE
   - Receive HTTP STATUS CODE + interpretation
   - Codes: 200/201/301/302/404/418/500/503/etc.
5. Check ORACLE HISTORY for past queries
```

**Oracle Logic:**
- Weighted random selection from 17 HTTP codes
- Interpretation contextual to question keywords (code, server, love, future)
- History persists in localStorage (max 10 entries)

### 📋 PHASE 5: FACTION ALIGNMENT (The Meta-Game)

**Location:** Hidden → Revealed via GOD MODE or Egregore Power 50+

```
1. Activate GOD MODE (Konami Code)
2. Hidden faction links appear in Webring:
   - VIRTUAL ADEPTS
   - HOLLOW ONES

3. Click any faction → Reputation track unlocks

   - Technocracy: Report "bugs" (console), order, structure

5. Reputation 100+ → Faction-specific ending
```

### 📋 PHASE 6: CHARACTER DOSIERS (Deep Lore)
